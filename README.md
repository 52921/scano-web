# Scano Web

Automatic Document & Aadhaar Scanner, Perspective Corrector & A4 Cyber Cafe Print Formatter.
100% client-side in-browser processing with zero server uploads.

Created by **Adhyan Sarthak**

## Features
- 🔍 Automatic 4-corner document edge detection.
- 📐 Projective Homography & Bilinear Interpolation perspective rectification.
- 🪪 Aadhaar Front + Back on single A4 sheet with cut guidelines.
- ✨ Magic Color & High-Contrast Xerox Photocopy filters.
- 🖨️ Direct Print & 300 DPI A4 PDF export.
- 🔒 100% private in-browser (Canvas & JS math).

## How to Run Locally
1. `npm install`
2. `npm run dev`
3. Open `http://localhost:3000`
